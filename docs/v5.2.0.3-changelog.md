# Clinical Trial Intelligence v5.2.0.3 changes

Native Windows setup now supports PostgreSQL without Docker through a hidden-password connector that creates only missing app roles/databases and verifies login. The ZIP still supports optional Docker and native Linux/macOS workflows.

The interface adds Manrope, clearer surfaces/spacing, a shared lazy 3D explanation engine with exact HTML evidence and accessible 2D fallback, explicit-click narration, reduced motion, Academy/home guidance and grouped appearance/scene settings with browser preference import/export/reset. All 26 routes remain.

Authenticated reload restores an authorized project/screen/dataset/study. Logout, expiry and membership loss clear stale intent. Assistant input expands to 32,768 characters with distinct general/project grounding; new projects use daily application quota 0 while existing limits and provider/abuse ceilings remain.

Expanded CatBoost candidate search is optional; standard/basic behavior remains compatible. Training-only preprocessing, tuning-only selection, held-out evaluation and explicit owner approval/activation remain required. Raw data, fixed PCI and approved model artifacts/metrics are preserved. No guaranteed accuracy improvement or clinical validation is claimed.

The current guide/PDF and release verification are separate from unchanged v5.2.0.2 historical documentation. See [the operating guide](v5.2.0.3-full-guide.md) for installation, all sections, the 37-check acceptance workflow and evidence limitations.
