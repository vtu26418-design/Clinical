## Scientific contract
- Fixed-reference PCI remains descriptive: sum w_i * clip(x_i/c_i,0,1), weights sum to 100. Publish component ceilings, missing-value convention and rounding; distinguish training-relative PCI in research artifacts.
- MAE, RMSE, R2, binary Brier, cosine similarity and planning arithmetic are exact named formulas with independently known-answer tests. Undefined metrics stay null.
- Planning recruitment months = target / (sites * monthly_rate_per_site); planned duration months = startup + recruitment + followup. These are explicit assumptions, not recruitment risk or causal clinical forecasts. No illustrative roadmap percentages are copied as output.
- Counterfactual model queries use only permitted protocol feature overrides, preserve source, label scenario predictions hypothetical and retain model/source provenance and cohort membership. Recruitment/amendment model probabilities remain unavailable without curated labels.
- Similarity is TF-IDF cosine descriptive retrieval with optional exact normalized phase filtering and self exclusion. Return data/source scope; not a clinical equivalence score.
- Add Gradient Boosting structured branch with bounded deterministic validation-only tuning. Retain six v3 branches on comparable splits.
- To provide uncertainty without calibration leakage, split original validation by whole start-date groups into earlier tuning and later calibration. Only tuning selects hyperparameters and recommended risk model. Calibration supports split-conformal residual intervals; finite-sample rank ceil((n+1)*(1-alpha)), unbounded if rank exceeds n. Nominal coverage relies on exchangeability and is not guaranteed under chronological shift. Probability calibration only when calibration support has both labels and sufficient counts; otherwise explicitly unavailable. Raw/calibrated semantics must match test metrics and recommendation.
- Training-derived numeric range/unseen category checks disclose extrapolation; no unsupported probability of OOD. Separate source/task/artifact versioning.

## Research API
GET /research/workspace?dataset_id&nct_id -> {study,pci:{score,category,components,methodology,missing_fields},duration,phase,similar:{items:[{study,similarity}],method,scope},phase_context:{phase,count,median_enrollment,median_pci},provenance:{dataset_id,sha256,source,is_fixture},risk_availability:{recruitment,amendment}}.
POST /research/scenarios -> {dataset_id,nct_id,overrides:{enrollment,number_of_arms,primary_outcomes,secondary_outcomes,criteria_count,text_complexity,phase},planning:{sites,monthly_rate_per_site,startup_months,followup_months},name}. All fields bounded finite numbers; sites/rate must be positive. The scenario enrollment overrides the recruitment target, else use source enrollment; missing target refuses rather than silently zero.
Response {id,name,created_at,base:{study,pci,duration},scenario:{study,pci,duration},planning:{target_enrollment,sites,monthly_rate_per_site,startup_months,followup_months,recruitment_months,total_months,formula,assumptions},changes:{pci, duration_days:null|number,probability:null|number},warning,provenance,evidence_sha256}. Immutable scenario persisted in local registry-backed table; no source mutation.
GET /research/scenarios?dataset_id&nct_id returns {items}.
GET /research/similar?dataset_id&nct_id&same_phase=true&limit<=10 returns similar object.
GET /research/evidence?dataset_id&nct_id returns {workspace,scenarios,generated_at,scope,evidence_sha256}; bounded JSON evidence packet. Routes authenticate, validate dataset IDs, safe errors; cache retrieval by canonical dataset fingerprint with bounded memory.
Frontend API signatures researchWorkspace(id,nct), scenario(id,nct,overrides,planning,name), scenarios(id,nct), evidence(id,nct). Preview computes the same fixed PCI/planning formulas and uses fixture retrieval snapshots; no fabricated fitted predictions.
