# CTI v3 Implementation Plan

> Agentic workers: use Superpowers implementation/review discipline; independently owned modules run in parallel.

**Goal:** deliver stronger real research comparisons plus an educational clinical-phase experience, integrated and runnable.
**Architecture:** extend existing React/FastAPI project; separate phase artifacts and existing duration tasks share trusted storage and a bounded worker. Native SVG/CSS illustrates concepts without fabricated outcomes.
**Tech stack:** Python 3.12, scikit-learn, pandas, FastAPI, React, TypeScript, Vite.
**Spec:** ../specs/2026-10-07-v3-design.md

## Global constraints

No fabricated real data/metrics, no frontend secrets, no post-outcome predictors, no test-set model selection, no claim of clinical validation. Preserve v2 design and use optional dependencies only when necessary.

## Review focus

- One-class and sparse phase support: explicit missing support/undefined metrics, no invented outputs.
- Tree models with sparse/constant inputs: deterministic bounded fitting and safe explanations.
- Chronological phase holdout: duplicate IDs/date groups and text label leakage guarded.
- Stale/mismatched task artifacts: reject wrong task/dataset/checksum before prediction.
- Paused/reduced motion: no autoplay animation that ignores user preference; all controls keyboard-operable.

## Tasks

- [ ] Models: research.py plus focused tests; add forest branches, validation-only recommendation, phase subgroup and chart diagnostics. Verify old and new tests.
- [ ] Phase ML: phase_model.py, CLI and tests; explicit cohort/split contract, majority baseline, linear classifier tuning, confusion matrix and safe artifact prediction. Verify exclusion/leakage/membership cases.
- [ ] Phase Academy: PhaseAcademy.tsx, phaseAcademy.css, phase content and source notes. Verify keyboard/playback/quiz/reduced motion and TypeScript.
- [ ] Data: retrieve a real bounded registry cohort, preserve raw responses/hash, create reusable downloader. No synthetic fallback.
- [ ] Integration: backend preflight/readiness/phase jobs/predictions/artifacts; frontend catalog/chart/model/phase workspace; focused API checks.
- [ ] Operations/release: diagnostics, docs, clean install/build/tests, independent review, hosted preview browser checks, archive/checksums and persistent ZIP.
