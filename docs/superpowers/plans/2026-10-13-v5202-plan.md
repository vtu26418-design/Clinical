# Clinical Trial Intelligence v5.2.0.2 Implementation Plan

> **For agentic workers:** use the parallel domain assignments below with test-first behavioral changes and independent whole-release review.

**Goal:** Deliver the user-authorized complete research application upgrade as a working PostgreSQL-backed ZIP with a guide PDF.

**Architecture:** Keep React/Vite, FastAPI, scikit-learn pipelines and existing project boundaries. Add full-cohort graph aggregation and evidence-connected visual components. PostgreSQL stores all metadata and assistant feedback; source/model files use persistent storage.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy, psycopg, PostgreSQL 16, React 19, TypeScript, Vite, Recharts, Markdown.

**Spec:** docs/superpowers/specs/2026-10-13-v5202-design.md

## Global Constraints

- Release version 5.2.0.2; PostgreSQL required, no SQLite fallback.
- Never fabricate measurements, probabilities, local attributions or confidence intervals.
- Preserve raw data and reproducible saved model artifacts; evaluate new candidates on temporal splits.
- Owner-only model training/approval, server-enforced project capabilities, validated feedback ownership.
- Minimal UI copy, navy/teal/white design, accessible responsive charts and reduced motion.
- Package current frontend build, guide PDF and checksums; exclude secret/runtime files.

## Review Focus

- Missing/partial dates and unsupported recruitment fields produce explicit unknown states.
- A fixture or unavailable model never produces invented predictions or SHAP values.
- A user cannot access/write another project's data through identifiers or feedback.
- Empty projects, revoked membership, reviewer/viewer POST reads and invitation links behave consistently.
- Network/provider errors show clear messages and preserve the user's conversation/scenario state.
