# Design fidelity and evidence decisions

Full-screen Overview, Explainability and Settings concepts informed the visual redesign. Release previews are screenshots of the running application with the authentic 800-record starter, not generated concept images.

| Reference checkpoint | Implemented result | Evidence or intentional adjustment |
|---|---|---|
| Palette and surfaces | Stone sidebar, evergreen ink, emerald actions, cool-white canvas and restrained panel borders | Actual desktop Overview and Settings screenshots |
| Typography and spacing | Self-hosted Manrope, readable controls, comfortable/compact density and visible focus | Licensed variable font included; mobile checks at 390px |
| Overview composition | Cohort summary, graph choices, source filters and comparison table | Original 12 graphs, exact cohort values and original 26 tools retained |
| Guided Explainability | True 3D evidence bars, selected-step caption, playback controls and accessible exact values | Uses actual saved-model signed contributions and units; original waterfall remains below |
| Settings composition | Vertical section rail, grouped controls and live conceptual scene preview | Original owner/role controls retained; email verification moved to Account |

Concept-generated extra navigation, invented study IDs/features, arbitrary chart bins and fake statistics were rejected. Trial dates come from the registry; scenes never imply an observed phase-transition history. Recruitment without observed funnel counts stays explicitly unavailable. Educational phase/DNA symbols are labelled conceptual. Expanded model search records evaluated candidates without silently changing approved artifacts.

Actual browser checks cover desktop/mobile, source study restoration beyond the initial 100 rows, 2D/3D switching, reduced motion, narration preference, context loss and WebGL absence. Dark controls/fallbacks/source labels were measured at a minimum 4.5:1 contrast; settings labels/surfaces were corrected during final visual review.
