## Start

Install Python 3.12, extract the complete ZIP and open a terminal inside `demand_forecasting`. Install dependencies in a virtual environment using `requirements-lock.txt`. Start/restart the dashboard with `python start_dashboard.py`; matching saved models load without retraining. For learning, run `python -m jupyterlab` and work through notebooks 01–04. `python run_week.py` reproduces the command-line stages. README.md has exact Windows and macOS/Linux commands.

## Model files and languages

`models/demo/` contains `linear_regression.joblib`, `random_forest.joblib`, `selected_model.joblib`, baseline JSONs, registry, manifest and model card. They are generated by this project's own code. Dashboard training persists new jobs under `models/runs/<dataset-id>/`. The earlier release generated a model only under `outputs/demo/model.joblib` after training.

Implementation languages are Python and Python Jupyter notebooks. Libraries follow the PDF: pandas, NumPy, scikit-learn, statsmodels, SQL, FastAPI and Streamlit/Plotly. XGBoost is optional under the PDF's "where appropriate" wording; the implemented learned candidates are Linear Regression and Random Forest. GitHub language percentages are descriptive, not prescribed.

## Learning and evidence

Every weekly guide explains what to do, how to implement it, topics, YouTube/website resources, checks and GitHub deliverables. Source, executed notebooks, actual fitted weights and tests are included. See the verification report for current test counts, notebook-kernel execution and extracted-archive checks. Weeks 1–2 are foundation milestones; fitted weights are included from Week 3 onward.

**Bundled sales are explicitly labelled synthetic practice data.** They make the project runnable without a Kaggle account or API key. For real internship findings, download licensed historical sales from [Store Item Demand Forecasting](https://www.kaggle.com/competitions/demand-forecasting-kernels-only/data) and follow `docs/DATA_GUIDE.md`. Inventory quantities are explicit what-if assumptions; no observed stock or supplier records are bundled. Distinguish supplied starter code and your own experiments in submissions.
