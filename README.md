# Clinical Trial Intelligence v5.2.0 downloads

This repository provides downloadable development-release assets for Clinical Trial Intelligence Workbench v5.2.0.

Open the Releases page while signed into GitHub. The draft release contains the all-downloads ZIP, animation walkthrough and PDF guides. The full upgraded project source, built interface, model artifacts and offline preview are inside the ZIP.

Source base: https://github.com/mprem27/Clinical-trail-mltimodelv5

The included feature-gap checklist explains partial and deferred capabilities. This is research decision-support software; the upgrade does not establish improved clinical predictive accuracy.
