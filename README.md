# UniEve Campus V1.1 downloads

This isolated branch contains the requested campus-project delivery. Clinical main and its application source are preserved.

Download UniEve-Campus-v1.1-source.zip for both source repositories and setup scripts, or UniEve-Campus-v1.1-mobile-web.zip for the built PWA demo. Read UniEve-Campus-v1.1-setup.md before configuring connected services.

Public university news was fetched live. Both manually answered AMS login attempts were rejected, so private attendance/student retrieval is unverified. This is an installable web app requiring HTTPS hosting for phone installation, not an APK. Real payments require merchant configuration.

Packages exclude portal credentials and private student data. The JSON manifest records SHA-256 hashes; the verification report describes tested behavior and limitations.
